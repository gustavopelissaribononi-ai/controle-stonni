Stonni Ar-condicionado
Aplicativo Stonni

Instale o controlee use pelo ícone, sem navegador.

Ele fala com o ar por Bluetooth e funciona sem internet — por isso roda instalado no celular, e não por esta página.

  • Não precisa ligar o ar. O controle conecta com o equipamento desligado.
  • É para celular Android. No computador não funciona.

Se o botão não aparecer, instale pelo menu do Chrome:

  1. Tocar nos três pontinhos no canto do Chrome
  2. Escolher Instalar app (ou Adicionar à tela inicial)
  3. Abrir pelo ícone da Stonni que aparecer na tela inicial
  1. Tocar nos três pontinhos e escolher Compartilhar
  2. Tocar em Adicionar à Tela de Início
  3. Não apareceu? Volte nos três pontinhos → Editar ações → toque no + em Adicionar à Tela de Início → Salvar, e repita o passo 2
  4. Abrir pelo ícone da Stonni na tela de início

Já instalou? É só abrir pelo ícone.

Requisições

O botão de varredura mostra qual comando vai varrer — troque o campo Cmd antes. Ele manda esse comando com os valores 0 a 9, um a cada 2,5 s, e escreve cada envio no log. Olhe o equipamento e veja em qual valor ele reage. Toque de novo para parar.

Âmbar no botão = enviado, aguardando o aparelho. As linhas confirmado… mostram quanto tempo cada comando levou para o equipamento responder. Painel de teste — 5 toques no logo escondem ou mostram.
